# Sistema-de-Calculo-de-IMC
Projeto que calcula o IMC (Índice de Massa Corporal) de acordo com os dados fornecidos pelo usuário. O sistema identifica se o usuário é homem ou mulher e, com base nisso, aplica regras e classificações específicas usando múltiplas estruturas condicionais (if/else). O programa também recebe peso e altura e retorna o nível do IMC.
